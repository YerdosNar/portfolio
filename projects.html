Projects

Here are some of the projects I have worked on:

Project Name Description Language Technologies Used
OpenP2P A Peer-To-Peer terminal application for messaging and file transfer. All traffic is End-to-End encrypted using LibSodium. C11 POSIX threads, LibSodium, Makefile, ASAN
3X-UI Auto A bash script to automate the installation of 3X-UI panel on a Ubuntu server. It installs all the required dependencies and configures the server for optimal performance. Bash Bash, Ubuntu, Docker, Caddy
PNG A terminal application to read throught the PNG file. It can find, inject, and remove hidden chunks. It uses convolution with different kernel to detect edges (Sobel, Laplacian, Gaussian, etc.) C11 Makefile, zLib (for compression and decompression)
DigitNN A neural network implementation to recognize handwritten digits from the MNIST dataset. It uses a simple feedforward neural network with backpropagation algorithm. C11 Makefile, SDL2
